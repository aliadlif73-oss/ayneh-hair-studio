# آینه — وب‌سایت مستقل معرفی محصول به مدیران سالن‌های زیبایی

## نمایش و انتشار
- پیش‌نمایش آزمایشی: https://ayneh-marketing-preview.3dingss.workers.dev/
- شاخه: `design/independent-marketing-site-teal`
- مسیر: `marketing-site/`
- تست: `node --test marketing-site/check.mjs`
- انتشار مستقل: `cd marketing-site && npx wrangler@4 deploy` (با حساب Cloudflare مجاز)
- کانفیگ: `marketing-site/wrangler.toml`، نام Worker: `ayneh-marketing` (جدا از Worker اصلی آینه)

## ساختار
- `index.html`: لندینگ فارسی، RTL، شش بخش فروش و فرم درخواست
- `assets/site.css`: طراحی ریسپانسیو؛ کرم گرم، سبز فیروزه‌ای، متن سرمه‌ای
- `assets/site.js`: منوی موبایل، اسلایدر قبل/بعد، اعتبارسنجی و ارسال درخواست
- `assets/*`: تصاویر واقعی موجود در مخزن آینه و فونت استداد
- `worker.js`: ارسال امن درخواست فرم به `https://ayneh-salon.site/api/inquiry`، با بررسی مبدأ و اندازه درخواست
- `preview-worker.js`: فقط برای پیش‌نمایش ابری؛ منابع کد و رسانه را از GitHub بارگیری می‌کند
- `_headers`: سیاست امنیتی نسخه استاتیک؛ `.assetsignore`: جلوگیری از انتشار فایل‌های توسعه

## تبدیل بازدیدکننده به مشتری
نمایش نتیجه روی عکس → مشاهده فرایند و مزایا → دموی واقعی → فرم درخواست معرفی. فرم با رضایت صریح، ارسال به API موجود آینه، honeypot و خطایابی تعاملی دارد؛ شماره موبایل روی سرور اعتبارسنجی می‌شود. هیچ رزرو آنلاین، داشبورد سالن یا آمار ساختگی ادعا نشده است.

## پیش از انتقال روی دامنه نهایی
- دامنه مستقل، لینک ارتباطی قطعی و سیاست حفظ حریم خصوصی تأیید شود
- بررسی مجوز استفاده از تصاویر و متن‌ها انجام شود
- `noindex` تنها پس از تأیید نسخه عمومی برداشته شود
- به جای نظرات و ارقام ساختگی، صرفاً نمونه‌های تأیید‌شده قرار گیرند
- ثبت موفق درخواست با اطلاعات تست مجاز، در محیط قابل کنترل صاحب پروژه بررسی شود
- سنجش واقعی عملکرد موبایل و دسترس‌پذیری انجام شود

هیچ فایل موجود در اپلیکیشن، D1، KV یا Worker اصلی تغییر نکرده است.
