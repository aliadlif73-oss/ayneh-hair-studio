# سایت مستقل معرفی و فروش آینه — نسخه اولیه طراحی

این پوشه مستقل از اپلیکیشن اصلی آینه است و هیچ مسیر، Worker یا تنظیم تولید را تغییر نمی‌دهد.

## مشاهده
فایل `index.html` را با مرورگر یا یک static server باز کنید. فایل‌های `assets/` از تصاویر واقعی موجود در همین ریپازیتوری به‌صورت بدون تغییر کپی شده‌اند.

## ساختار
- Hero: توضیح مستقیم محصول به مدیر سالن + قبل/بعد تعاملی
- مزایا: کاربردهای واقعی، بدون ادعای رشد درآمد اثبات‌نشده
- نحوه کار: عکس → انتخاب → تولید → درخواست
- خدمات: مدل مو، رنگ، مژه، ناخن و دریافت درخواست از پیام‌رسان
- نمونه واقعی و شفافیت محدودیت تصویر AI
- CTA، پرسش‌های متداول و فوتر

## قبل از انتشار
- نام دامنه سایت مستقل و مسیر تماس/درخواست دمو تعیین شود
- مسیرهای CTA به جای دامنه فعلی به فرایند فروش نهایی متصل شوند
- بررسی مجوز استفاده از تصاویر و دریافت رضایت
- حذف noindex پس از تأیید نهایی محتوا و انتشار
- تست موبایل فیزیکی، تست دسترس‌پذیری و سنجش سرعت
- در صورت دریافت تأییدیه واقعی، نظرات سالن‌ها با اجازه آنها اضافه شوند

هیچ آمار ساختگی، رزرو آنلاین یا پنل مدیریت سالن در این نمونه به عنوان قابلیت واقعی معرفی نشده است.
